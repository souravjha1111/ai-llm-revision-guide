# AI / LLM Engineering — Revision Guide

A lightweight, responsive, static interview-revision website.

## Files
- `index.html` — guide content and learning index
- `styles.css` — responsive dark theme
- `app.js` — topic search and keyboard shortcut

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/ (root)**, then Save.
4. Wait for the Pages deployment to finish. The site URL will be shown on that page.

The expected URL for this repository is:
`https://souravjha1111.github.io/ai-llm-revision-guide/`

## Updating the guide
Keep the roadmap intact. Add detailed notes only after a topic has actually been covered. Prefer concise definitions, mental models, diagrams, practical trade-offs, and interview checks over long-form explanations.
